Cude – Responsive Portfolio Website

A responsive portfolio-style website built using HTML5 and CSS3.This project includes sections for services, team members, skills, portfolio projects, testimonials, and a contact form.

✨ Features

Responsive design for mobile, tablet, and desktop screens
Navigation/header section
Services section
Team members section
Skills/progress section
Portfolio/projects section
Testimonials section
Contact form
Social media footer links
Font Awesome icons
CSS media queries for responsive layouts

🛠️ Technologies Used:-

HTML5
CSS3
Font Awesome
Responsive Web Design

📱 Responsive Design

The CSS contains responsive breakpoints for:
Mobile: default styles
Tablet: min-width: 768px
Desktop/Laptop: min-width: 1024px
The layout changes from single-column sections on smaller screens to multi-column layouts on larger screens.
