📌 About the Project
This portfolio website presents my background and work as a developer in a clean, modern interface. It uses a dark gradient theme with purple accents, interactive hover effects, responsive layouts, and a light-mode option.
The website is built with HTML5, CSS3, and JavaScript, with Font Awesome icons and Google Fonts for visual styling.

⚙️ Run Locally
No build tools are required for this static website.
1. Clone the repository:
   git clone https://github.com/aishwaryakesarkar599-arch/Portfolio.git
2. Open the project folder:
   cd Portfolio
3. Open index.html in your browser.
   Alternatively, open the folder in Visual Studio Code and run index.html with the Live Server extension.
If your repository has a different name, replace Portfolio in the clone URL and folder command with the correct repository name.

🌍 Deployment
This website can be hosted using GitHub Pages:
1. Push the portfolio files to your GitHub repository.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the main branch and / (root) folder.
6. Click Save and wait for deployment.
7. Add the generated website URL to the Live Portfolio link near the top of this README.
